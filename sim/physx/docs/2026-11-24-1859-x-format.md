# X: the physics output of p2s_sim

`p2s_sim S.json out/` writes `out/x.json` and `out/streams/`. The checker (`p2s_check`) and the Blender importer
(`sim/blender/import_x.py`) read only this. Everything is in the world frame (Z up, metres, seconds), one record per
recorded frame: frame `f` is at `t = f / fps`.

## x.json

| key | what |
|---|---|
| `format`, `version` | `"p2s-x"`, `1` |
| `scene` | `name`, and `meta` copied from S |
| `clock` | `fps`, `frames`, `substeps`, `dt` (physics step), `preroll_s` |
| `gravity`, `wind`, `materials` | as simulated (wind: `velocity`, `gust`, `turbulence`, `turbulence_length_m`, `air_density`) |
| `water` | null, or `{level, density, current, min?, max?}`: the flat water surface (the renderer draws it) |
| `entities` | one object per entity: `id`, `kind`, its geometry and parameters, and `streams` (below) |
| `assemblies` | entity id to assembly name: entities in one assembly never collide (a vehicle and its crumple zone) |
| `cameras` | `id`, `type`, `fov_deg` (horizontal), `resolution` [w, h], `clip_m` [near, far], `spec` (the S entry) |
| `triggers` | what fired, in words |
| `events` | `[{name, t, data?}]` in time order: `contact:<a>:<b>` (first touch, ids sorted), `<id>:lift_off`, `<id>:stops`, `<id>:moves`, `<id>:passes_stop_line` (`data.light`), `<id>:broken`, `<signal>:<colour>`, `trigger:<id>:<verb>`, ... |
| `contacts` | per pair: `first_t`, `last_t`, `total_impulse_ns`, `peak_force_n`, `touch_steps` |
| `actuators` | per actuator (`<entity>/<name>`): `kind`, `carried_mass_kg`, `peak_force` with `force_unit`, `peak_power_w`, `work_in_j`, `work_out_j` |
| `streams` | per stream key: `file`, `width`, `rows` (a number, or `"variable"` with a `count_file`), or `static` + `dtype` |
| `run` | `wall_seconds`, `steps`, `fine_steps`, `device`, `physx_errors`, `physx_messages` |

### Geometry: `parts`

Rigid entities describe themselves as parts. A part moves as one rigid unit:

```json
{"name": "chassis", "shapes": [...], "stream": "body/truck/pose", "row": 0, "kind": "wheel"?}
```

`shapes` are p2s shapes in the part's frame, exactly what PhysX collided: `{"type", "pos", "quat_xyzw",
"material", ...}` with `half_extents` (box), `radius` (sphere), `radius` + `half_length` (capsule and cylinder,
axis along local Z), or `vertices` + `triangles` (+ `planes` for convex shapes; prisms and convex hulls as cooked).
The pose of the part at frame `f` is row `row` of frame `f` of its stream.

| kind | parts |
|---|---|
| `rigid_body`, `multirotor`, `tracked_vehicle`, `walker` | `body` |
| `vehicle` | `chassis`, then `wheel0` ... `wheel<n-1>` (front axle first, left wheel first) |
| `robot_arm` | one per link (`link0` ... `hand`, fingers), with `visuals` (MJCF mesh files for rendering) |

## Streams

Raw little-endian float32 (`.f32`) or int32 (`.i32`) files, row-major. A fixed stream holds `frames * rows * width`
values. A variable stream (particles) holds all frames' rows back to back; `count_file` has the row count per frame.

| key | width | rows | contents |
|---|---|---|---|
| `body/<id>/pose` | 7 | 1 | position, quaternion x y z w |
| `body/<id>/vel` | 6 | 1 | linear velocity, angular velocity (world, rad/s) |
| `vehicle/<id>/wheels` | 7 | wheels | wheel poses (spin and steer included) |
| `vehicle/<id>/controls` | 4 | 1 | throttle, brake, steer (-1..1, + left), forward speed |
| `multirotor/<id>/rotor_omega` | rotors | 1 | rotor speeds, rad/s |
| `multirotor/<id>/thrust_tilt` | 2 | 1 | total thrust N, tilt rad |
| `tracked/<id>/drive` | 3 | 1 | target speed, drive force, on ground (0/1) |
| `robot/<id>/links` | 7 | links | link poses |
| `robot/<id>/joints` | links + 2 | 1 | joint value per link (rad or m, 0 without a joint), IK error m, IK error deg |
| `walker/<id>` | 4 | 1 | walk phase (0..1 per 1.5 m stride), walking (0/1), speed, pose id (0 walk, 1 stand, 2 phone) |
| `joint/<id>` | 2 | 1 | broken (0/1), angle rad or position m |
| `signal/<id>` | 1 | 1 | 0 red, 1 yellow, 2 green |
| `softbody/<id>/verts` | 3 | vertices | world positions of the collision mesh |
| `softbody/<id>/tets`, `/triangles` (static, int32) | 4, 3 | | tetrahedra; outward surface triangles |
| `softbody/<id>/rest` (static) | 3 | vertices | rest positions (host frame when hosted, else world) |
| `cloth/<id>/verts` | 3 | vertices | world positions |
| `cloth/<id>/triangles` (int32), `/uv` (static) | 3, 2 | | triangles; texture coordinates (0..1 across the rectangle) |
| `particles/<id>/pos` | 3 | variable | alive particles' positions |
| `camera/<id>` | 7 | 1 | camera pose, Blender convention (looks down local -Z, +Y up) |
| `world/energy` | 4 | 1 | kinetic J, potential J (z = 0 reference), net actuator work J, positive actuator work J |

Reading a stream in Python:

```python
import json, numpy as np
x = json.load(open("out/x.json"))
s = x["streams"]["body/truck/pose"]
pose = np.fromfile("out/" + s["file"], dtype="<f4").reshape(x["clock"]["frames"], s["rows"], s["width"])
```
