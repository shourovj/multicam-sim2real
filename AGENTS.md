# Agent notes

## Docs workflow

- Markdown drafts in `docs/` are first drafts. The user pastes each one into the [design doc Google Doc](https://docs.google.com/document/d/1cAho8uc2gT9nnzAg9GN1NU0pHQ4cggaQcGlL9v-IBb4/edit?usp=sharing), one tab per version, and then edits, annotates, and comments there.
- Before revising a doc or writing the next version, read the current Google Doc, including its comments. Treat it as the source of truth over the local `.md`, and carry over the user's edits and answer or resolve their comments. If the Google Doc can't be read, ask the user to paste the current text.
- New versions go in a new file (`docs/design-doc-v1.md`, ...) that matches a new tab, not an overwrite of the old one.
