# Agent notes

## Docs

- Doc filenames start with a local date-time stamp, `YYYY-MM-DD-HHMM-`, e.g. `docs/2026-11-09-1416-design-doc-v0.md`.
- Some Markdown docs get pasted into the [design doc Google Doc](https://docs.google.com/document/d/1cAho8uc2gT9nnzAg9GN1NU0pHQ4cggaQcGlL9v-IBb4/edit?usp=sharing). Those that are may be linked to their tab in the table in the README `Docs` section.

## Artifacts

- When you publish a new claude.ai artifact for this project (page, slides, doc, dashboard), add a row to the `Artifacts` table in the README in the same change: link, kind, author, creation date (`YYYY-MM-DD`), and one line on what it covers. Keep the table oldest first.
- Add one when someone shares a project artifact with you too. If the author isn't known, say so in the row rather than guessing.
- Default sharing for a new project artifact: everyone in the UT Austin org can comment. Set it when you publish. If your tools can't set sharing, tell the user to set it from the artifact's Share menu.
